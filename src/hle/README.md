# MusyX v1 HLE (from mupen64plus-rsp-hle)

These files are unmodified copies from [mupen64plus-rsp-hle](https://github.com/mupen64plus/mupen64plus-rsp-hle)
at commit `8a7a472a7172eb2c8725b305eae26818ed7b51a2`, licensed GPL-2.0-or-later (see each file's header), which
this project uses under GPL-3.0.

Only `musyx_v1_task` and what it needs are taken. `src/musyx_hle.cpp` supplies the `hle_t` state and the
external functions mupen's plugin normally provides. Rush 2049 is one of the games mupen lists for MusyX v1.
