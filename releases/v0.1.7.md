San Francisco Rush 2049: Recompiled v0.1.7: on Linux, the log of a game that hangs says where it was stuck.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.7-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.7-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Changed (Linux):** if the game hangs and you end it (Exit Game in Steam, closing it in the Steam Deck's game mode, or `kill` with its process id), `rush2049.log` now ends with what every thread was doing, so a hang can be tracked down from the log. Ending it that way also no longer crashes on the way out. If it hangs, send that log before starting the game again (a new start keeps the old one as `rush2049.old.log`).

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
