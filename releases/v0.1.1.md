San Francisco Rush 2049: Recompiled for Windows, v0.1.1: the game no longer opens a console window behind it. Nothing else changes from v0.1.0.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**To play:** unzip `Rush2049Recompiled-v0.1.1-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (that folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**. Settings and saves carry over from v0.1.0.

**Changed:** only the game's window opens now. To see the log, as the console showed it, run `Rush2049Recompiled.exe --show-console`.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
