San Francisco Rush 2049: Recompiled v0.1.3: Rewind no longer crashes the game after heavy use, and the game keeps a log you can send in when something goes wrong.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.3-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.3-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed:** using Rewind a lot, in one race or across several, made the game crash: each rewind left behind some of the looping sounds started in the stretch it undid, still waiting to play, until the game ran out of sounds. Letting go of Rewind now releases them.

**New:** started without a console (from Explorer, or a Linux desktop launcher rather than a terminal), the game writes its log to `rush2049.log` in the folder its settings are in: beside the exe if you have a `portable.txt` there, otherwise `%LOCALAPPDATA%\Rush2049Recompiled\` on Windows and `~/.config/Rush2049Recompiled/` on Linux. The run before is kept as `rush2049.old.log`. If the game crashes, the log ends with where it crashed (the Windows zip now carries `Rush2049Recompiled.pdb` so that trace names the game's own functions, which is why it is twice the size). Please open an [issue](https://github.com/n64hub/rush-2049-recomp/issues) with `rush2049.log` attached (or `rush2049.old.log`, if you have started the game again since) and say what you were doing. `--show-console` still shows the log live instead.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
