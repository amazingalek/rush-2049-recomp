San Francisco Rush 2049: Recompiled v0.1.17: a controller that reconnects works again without a restart.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.17-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.17-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed:** a controller that disconnected and came back (a Bluetooth drop, a cable pulled and plugged in again) gave the game no input until it was restarted: it came back as a new controller, and its player kept waiting on the old one. It is now that player's controller again. The log (`rush2049.log`) also names each controller it finds, which helps with a report of a controller problem.

The [README](https://github.com/amazingalek/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
