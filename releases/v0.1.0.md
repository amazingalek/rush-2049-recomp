The first release of San Francisco Rush 2049: Recompiled for Windows: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**To play:** unzip `Rush2049Recompiled-v0.1.0-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. The launcher finds your ROM by itself in a usual place (that folder, Downloads, Desktop, Documents and one level of subfolders); otherwise pick it with **Load ROM**.

**What works:** menus, Single Race, Circuit, Ghost Race, Stunt and Battle at full speed, all six race tracks, two- and four-player split screen, and Controller Pak saves.

**Enhancements**, each an option in the settings menu with an Original value that runs the game as it shipped:

- High resolution at the window's size, with 2× MSAA
- Hi-res menu and HUD text, and a hi-res title screen
- 60 fps game logic, interpolated up to a high-refresh monitor's rate
- Lower input lag
- Widescreen 3D, HUD, split screen and menus
- Enhanced audio: a 44.1 kHz MusyX mix with no clipping or dropouts
- Rewind in single-player races
- Large Controller Paks (about 1.9 MB each), and Rumble Pak
- Keyboard and gamepad controls, rebindable

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
