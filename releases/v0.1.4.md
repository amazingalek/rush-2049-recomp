San Francisco Rush 2049: Recompiled v0.1.4: Race Again after a Ghost Race no longer freezes, ghosts can be saved, every controller is a player of its own, and races rumble with saves still working.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.4-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.4-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed:** Race Again, right after finishing a Ghost Race, sometimes hung on the loading screen for good. It depended on the ghost just recorded, so it came and went from race to race.

**New:**

- **Save Ghosts** (General tab, On by default): after a Ghost Race finished inside the time limit, the game's own SAVE GHOST prompt comes up and writes the ghost to the Controller Pak, where it is offered in later Ghost Races on that track, after a restart too. As shipped, the game kept a ghost only until you quit and showed the prompt only for a developer's profile name. Saving needs a player profile on the pak: Just Play has none, so it keeps the ghost for the session. **Original** turns the prompt off.
- **Several players:** each controller is a player of its own, as on the console. The first controller to press a button is player 1, the next one player 2, and so on up to 4, and the keyboard drives player 1. **Assign Players** on the Controls tab puts them in another order, and each controller has bindings of its own there, starting from the one-player ones. Before, every controller drove player 1; **Controllers** (General tab) at **One Player** still does that. Split screen with a controller for each player has only been tried with virtual controllers so far, so reports are welcome.
- **Controller Accessory** has a new value, **Both**, now the default: every controller has a Controller Pak and a Rumble Pak at once, so races rumble, for every player, and saves still work; the RUMBLE setting in each player's CONTROLS screen applies, and the game no longer asks you to insert a Rumble Pak. Before, it was one or the other (Controller Pak by default); **Controller Pak** and **Rumble Pak** are still there.
- **Linux:** the game now runs on a Vulkan driver without descriptor indexing (such as Debian 12's software driver), and two graphics bugs that a strict driver could trip on are fixed. It has still been run only with a software Vulkan driver.

On a Steam Deck, or started from Steam, the Nintendo Switch Online N64 controller's C-Right never reaches the game unless Steam's controller layout maps it: the README says how.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
