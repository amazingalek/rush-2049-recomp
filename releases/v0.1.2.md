San Francisco Rush 2049: Recompiled v0.1.2: the first Linux build, beside the Windows one. The game itself is the same as v0.1.1.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.2-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. Settings and saves carry over from earlier versions.

**Linux (new, x86-64):** extract `Rush2049Recompiled-v0.1.2-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder. It needs glibc 2.35 or newer (Ubuntu 22.04, Debian 12 or later), a Vulkan driver, and GTK 3 and FreeType, which desktop distributions have; it brings its own SDL2. Settings and saves go in `~/.config/Rush2049Recompiled/`. It has been run only with a software Vulkan driver, where it boots and plays the title screen and attract races; nobody has played it on a Linux GPU or a Steam Deck yet, so reports are welcome.

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
