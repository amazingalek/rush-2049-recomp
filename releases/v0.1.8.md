San Francisco Rush 2049: Recompiled v0.1.8: on Linux, the log is written when the game is started from Steam.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

You need your own ROM of the US release (`.z64`, SHA-1 `3f99351d7bb61656614bdb2aa1a90cfe55d1922c`); the launcher finds it by itself in a usual place (the game's folder, Downloads, Desktop, Documents and one level of subfolders), otherwise pick it with **Load ROM**.

**Windows:** unzip `Rush2049Recompiled-v0.1.8-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.8-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves carry over from earlier versions.

**Fixed (Linux):** started from Steam (Game Mode on the Steam Deck too), the game wrote no `rush2049.log`, since Steam keeps a game's output in a log of its own. It now writes `rush2049.log` however it is started, except from a terminal, where the log is printed instead: beside the game with a `portable.txt`, otherwise in `~/.config/Rush2049Recompiled/`. If the game hangs, end it (Exit Game in Steam) and send that log before starting it again (a new start keeps the old one as `rush2049.old.log`).

The [README](https://github.com/n64hub/rush-2049-recomp#readme) has the controls, every setting, and how to build it yourself.
