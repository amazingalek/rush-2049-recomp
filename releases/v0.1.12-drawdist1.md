San Francisco Rush 2049: Recompiled v0.1.12-drawdist1: a test build for [#211](https://github.com/amazingalek/rush-2049-recomp/issues/211), to find what makes scenery pop in. It is not a release: to play, use [v0.1.12](https://github.com/amazingalek/rush-2049-recomp/releases/tag/v0.1.12).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

It is v0.1.12 with one added setting, **Graphics → Draw Distance (debug)**, which can be changed mid-race (pause, open the settings menu, pick a value, go back). Each value sets one of the game's distance limits to four times its own:

- **Original**: the game as it shipped.
- **Far plane 4x**: the far plane, past which nothing is drawn (and the distance split screen drops scenery at).
- **Matrix limit 4x**: the distance on any one axis past which a piece of scenery isn't placed at all.
- **LOD cutoff 4x**: the distance past which a model is no longer drawn.
- **LOD detail 4x**: the distances at which a model switches to a less detailed version.
- **All 4x**: all four.
- **All 1/4 (check)**: all four cut to a quarter instead. Far scenery (the bridge, the sky) disappears, which shows that the setting works.

On the tracks tried so far, All 4x draws exactly the same picture as Original. If something pops in for you, please note the track and where it happens (a screenshot or a short clip helps), then try the values: the one that stops the pop-in names the cause, and if none does, that is just as useful to know.

**Windows:** unzip `Rush2049Recompiled-v0.1.12-drawdist1-windows-x64.zip` and run `Rush2049Recompiled.exe` from that folder. **Linux (x86-64):** extract `Rush2049Recompiled-v0.1.12-drawdist1-linux-x64.tar.gz` and run `Rush2049Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType). Settings and saves are shared with the release. Before going back to v0.1.12, set the setting back to Original: it will ignore the setting, but then nothing is left over.
