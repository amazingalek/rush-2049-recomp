## Triage (`py -3 -I tools/rom_triage.py <rom>`)

- **Graphics ucode: `RSP Gfx ucode F3DEX.NoN fifo 2.08 Yoshitaka Yasumoto 1999 Nintendo.`** This
  is F3DEX2 2.08 NoN `.fifo`, which is in RT64's supported table (see
  [../01-toolchain.md](../01-toolchain.md#3-rt64)). The biggest blocker class is cleared.
- **No compression magics.** No Yaz0, Yay0, MIO0 or gzip; the zlib-header counts (136/157) are
  what chance predicts for 2-byte patterns in 12 MiB. The ucode string is readable in plain
  text, which also points to uncompressed code. Code layout still needs confirming with a
  disassembly.
- No audio ucode string found. The audio driver is unknown so far.
